## 作者簡介

[陳佳新](https://www.facebook.com/jarsing.7816)：彰化軟體公司[奇步應用](https://fb.com/chibuapp)（ChiBuApp Inc.）執行長，是國際資訊大廠官方認證的LINE API Expert聊天機器人技術專家暨微軟AI MVP人工智慧最有價值技術專家，同時也是Chatbot Developers Taiwan中部分舵、GDG Changhua、彰化AMA小聚等社群活動的主辦人，經常在COSCUP、MOPCON、.NET Conf等開發者年會擔任講者，致力於提升故鄉彰化的數位化能力，立志成為地方創生和永續發展最強而有力的數位轉型支持系統。

## 作者序

感謝四位微軟MVP前輩惠賜合著本書的機會，佳新非常榮幸和開心能夠參與其中，在半年內一起接連完成了兩本書，所以這是我個人的第二本電腦著作。筆者負責第七章，分述以LINE Bot MCP Server搭配Claude for Desktop AI Agent與天氣查詢MCP Server搭配Google Gemini AI Agent，從開發到實現的內容。

考量到讀者的開發環境，本次書寫的程式範例都可以在本機上（例如Mac電腦）完成部署。此外，身處在與AI協作寫程式（Vibe Coding）盛行的年代，各種Node.js版本與套件安裝的疑難雜症，都可以獲得良好且迅速的解決。

最後，一如既往，謹將本書獻給Viki、Linus和Morris，我最鍾愛的奇步一家人。是你們支持我成為彰化最強，並且逐夢踏實地在故鄉彰化創辦軟體公司和舉辦小聚，以數位力推動地方創生和永續發展的成長飛輪（Flywheel）。

親愛的讀者們，請坐穩了，LINE Bot MCP Server和Google Gemini AI Agent的學習列車，即刻啟程！ 🚀

陳佳新
奇步應用 執行長
2025年6月於彰化
